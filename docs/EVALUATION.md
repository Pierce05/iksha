# Evaluation protocol
12 messages: 8 pattern-based (write yourselves, fictional data), 4 legitimate. 8–10 target-like participants.
Round 1: show 6 messages, log "would you pay/click/join?" in `eval-sheet.csv`. Teach with the SACH ledger. Round 2: new messages, same patterns. Also run SACH on all 12 and log output.
Report counts, not invented percentages: risky decisions before/after, false alarms on legitimate messages, SACH's own misses, sample size. Claim "teaches tactics", not "solves fraud".
